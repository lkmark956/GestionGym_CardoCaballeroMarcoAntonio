🚀 INICIO RÁPIDO (3 pasos)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. INSTALAR DEPENDENCIAS
   Abrir terminal en esta carpeta y ejecutar:
   
   pip install -r requirements.txt


2. CREAR DATOS DE PRUEBA (Opcional)
   Para probar el sistema con datos de ejemplo:
   
   python datos_prueba.py
   
   Esto creará:
   - 5 clientes
   - 10 aparatos
   - 6 reservas
   - 5 recibos (3 pendientes, 2 pagados)


3. EJECUTAR LA APLICACIÓN
   
   python main.py


¡Listo! La aplicación se abrirá con una interfaz moderna.

🔧 SOLUCIÓN RÁPIDA DE PROBLEMAS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Error al instalar CustomTkinter:
   → pip install --upgrade pip
   → pip install customtkinter pillow

❌ Error "No module named 'database'":
   → Asegúrese de estar en la carpeta del proyecto
   → Ejecute desde la raíz: python main.py

❌ La aplicación no arranca:
   → Verifique que Python 3.8+ esté instalado: python --version
   → Instale de nuevo las dependencias

❌ No se crean los datos de prueba:
   → Elimine el archivo gimnasio.db si existe
   → Ejecute de nuevo: python datos_prueba.py
